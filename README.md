# LangChain Learning Log

This repo is a collection of small scripts and notebooks I'm building while learning LangChain — mostly following along with tutorial videos and experimenting on my own.

It's not a polished project, just a working record of concepts as I pick them up: chains, prompts, memory, retrieval, agents, and eventually LangGraph.

## Structure

```
├── 01_basics/          # LLMChain, prompts, output parsers
├── 02_memory/           # conversation memory types
├── 03_rag/              # document loaders, embeddings, vector stores
├── 04_agents/           # tools, agents, agent executors
└── 05_langgraph/        # graph-based workflows
```

Each folder has small, self-contained scripts with comments explaining what's being tested.

## Why this repo

I'm using this as a running log while transitioning into GenAI work, so I can look back on what I've covered and show it as example work alongside my other projects.

## Stack

- LangChain (LCEL / Runnables)
- Groq API / OpenAI (varies by script)
- Python

## Notes

Code here is for learning, not production — expect quick experiments over clean architecture.
